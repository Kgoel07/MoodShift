# MoodShift logo

Save your logo here as `logo.png`. Use a square PNG, ideally 128 × 128 pixels with a transparent background.

Rebuild the extension from the project root and reload MoodShift in `chrome://extensions`. The build uses the image in the side panel, toolbar, and Chrome extension list.

```sh
npm run build:extension -- --mode production
```

For the development build, run `npm run build:extension`.
